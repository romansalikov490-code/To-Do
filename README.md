# План · AI Task Manager

Next.js, TypeScript, Tailwind CSS, Turso и Gemini. Авторизации нет: все посетители одной установки имеют доступ к одним задачам. Запускайте приложение в доверенной среде.

## Запуск

1. Установите Node.js 20+ и выполните `npm install`.
2. Создайте базу Turso и получите её URL и токен. Скопируйте `.env.example` в `.env.local` и заполните `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN` и `GEMINI_API_KEY`. Ключи используются только на сервере.
3. Выполните `npm run dev` и откройте http://localhost:3000. Таблицы создаются автоматически при первом запросе.

Задачи, созданные в предыдущей версии интерфейса в этом браузере, автоматически переносятся в базу после успешного подключения. Голосовой ввод требует поддерживающего Web Speech API браузера и разрешения на микрофон. Для AI-функций нужен ключ с доступом к `gemini-3.5-flash`.

Для локальной проверки базы можно указать `TURSO_DATABASE_URL=file:local.db` и оставить токен пустым. Для AI всё равно нужен ключ Gemini. Файлы локальной базы и окружения не следует публиковать.
